# 乐乐云 ERP

乐乐云财务工作台的静态前端演示项目。

## 当前范围

- 纯前端页面，由 HTML、CSS 和 JavaScript 构成。
- 页面状态与演示数据保存在当前浏览器的 localStorage 中。
- 登录状态只是界面展示；当前版本没有服务端、真实身份认证、跨设备同步或云端数据存储。
- 请勿将真实财务数据、账户密码或支付信息录入此演示版本。

## 本地查看

直接打开 `index.html`，或使用任意静态网站服务器托管本目录。

## GitHub Pages

仓库为私有仓库。若要通过可分享链接访问 GitHub Pages，请在仓库的 **Settings → Pages** 中检查账号套餐是否允许从私有仓库发布。启用后，GitHub 会显示站点 URL。私有源代码仓库不代表发布后的站点一定私有；请在分享链接前确认站点访问范围。

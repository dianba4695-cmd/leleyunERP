# 乐乐云 ERP

乐乐云财务工作台的静态前端演示项目。

## 当前范围

- 纯前端页面，由 HTML、CSS 和 JavaScript 构成。
- 页面状态与演示数据保存在每位访问者当前浏览器的 localStorage 中，不会在不同用户或设备间同步。
- 登录状态只是界面展示；当前版本没有服务端、真实身份认证、跨设备同步或云端数据存储。
- 请勿将真实财务数据、账户密码或支付信息录入此演示版本。
